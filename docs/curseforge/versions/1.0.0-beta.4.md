<h2>v1.0.0-beta.4 - Magic Circle Shader Fix</h2>

<h3>Fixed</h3>
<ul>
<li><strong>Fixed the Enchanting Table Magic Circle rendering as a blurry, shapeless blob</strong> instead of
  the crisp glowing ring/rune art. The <code>entity.fsh</code> shader (ported to the 26.2 vanilla base) applied
  the vertex-color/<code>ColorModulator</code> multiply and the overlay blend <em>before</em> the conditional
  lightmap multiply (skipped for alpha-252 emissive pixels), instead of after &mdash; the reverse of the
  original pack's order. Reordered to match the original exactly: light &rarr; vertex color &times;
  <code>ColorModulator</code> &rarr; overlay.</li>
<li>Verified via a full byte-for-byte diff (154 files) against the original reference pack: the book model,
  circle/rune textures, and animation properties were already identical &mdash; this shader was the only
  functional difference.</li>
</ul>
