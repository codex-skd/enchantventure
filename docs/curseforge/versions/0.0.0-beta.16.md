<h2>v0.0.0-beta.16 - Cleanup &amp; new mod</h2>

<p>This release cleans up the pack and fixes a broken translation that shipped in earlier betas.</p>

<h3>Added</h3>
<ul>
<li><strong>Workhand Tools</strong> (<code>workhand_tools</code>): Spanish translation (es_ES), 28 keys —
  new mod in the instance without its own <code>es_es.json</code>.</li>
</ul>

<h3>Fixed</h3>
<ul>
<li><strong>Stellarity</strong> (<code>stellarity</code>): the <code>es_es.json</code> in the pack was
  corrupted with ~36k keys from the mod's obfuscation map (namespace <code>space</code>). Rewritten from
  scratch as a real Spanish translation of the 645 keys in <code>en_us.json</code>.</li>
</ul>

<h3>Removed</h3>
<ul>
<li><strong>Non-Spanish language files</strong>: 279 <code>lang/*.json</code> files (de_de, en_us, fr_fr,
  it_it, ja_jp, ko_kr, pt_br, ru_ru, zh_cn) removed — this pack only carries <code>es_es.json</code>.</li>
<li><strong>Obsolete asset folders</strong>: 15 folders for mods no longer in the instance or replaced by
  the correct namespace (<code>ancient-artifacts-2</code>, <code>better-compatibility-checker</code>,
  <code>better_party_x_waystones</code>, <code>gatewayofdoom</code>, <code>hammersandexcavators</code>,
  the old Moog's and Dungeons &amp; Taverns folders, <code>teleport_animation</code>,
  <code>netherportalfix</code>, <code>shogi</code>).</li>
</ul>

<h3>Notes</h3>
<blockquote><code>netherportalfix</code> and <code>shogi</code> had empty <code>es_es.json</code> files —
removed. The pack is now exactly 88 asset folders, one <code>es_es.json</code> each.</blockquote>
