<h2>v1.0.0-beta.2 - Clarified magic circle requirements</h2>

<p>Documentation release: clarifies the mods required for the Enchanting Table Magic Circle
(the requirements from the original pack by Jacosvaldo).</p>

<h3>Documented</h3>
<ul>
<li><strong>EMF</strong> (Entity Model Features) or <strong>OptiFine</strong> — required for the custom
  book model (<code>optifine/cem</code>).</li>
<li><strong>ETF</strong> (Entity Texture Features) or <strong>OptiFine</strong> — required for the
  animated / emissive textures (<code>optifine/anim</code>, <code>_e</code> overlays).</li>
<li><strong>Animatica is Fabric-only</strong> and does not apply to NeoForge.</li>
<li><strong>Respackopts</strong> remains optional (circle color / animation mode); without it the
  default blue circle is used.</li>
</ul>

<p>README, CurseForge description and the project workflow were updated accordingly.</p>
