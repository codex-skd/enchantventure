<h2>v1.0.0-beta.6 - Fix rejected upload</h2>

<h3>Fixed</h3>
<ul>
<li><strong>CurseForge upload rejection</strong>: the 1.0.0-beta.6 ZIP was byte-identical to 1.0.0-beta.4
  (no content changes in <code>resourcepack/</code>, and <code>pack.mcmeta</code> never included the
  version string), which caused CurseForge to reject it as a duplicate file fingerprint.</li>
<li>Added the version number to <code>resourcepack/pack.mcmeta</code>'s <code>description</code> so every
  build produces a unique ZIP, even between betas with no translation changes.</li>
</ul>
