<h2>v1.0.0-beta.7 - Remove Enchanting Table Magic Circle</h2>

<h3>Removed</h3>
<ul>
<li><strong>Enchanting Table Magic Circle</strong> (retextured animated magic circle on the enchanting
  table book, integrated since 1.0.0-beta.1): removed entirely — <code>respackopts.json5</code>,
  <code>assets/minecraft/optifine/</code>, <code>assets/minecraft/shaders/</code>,
  <code>assets/minecraft/textures/entity/</code> (book/circle/runes) and
  <code>assets/enchantinginfuser/textures/</code>, plus the <code>rpo.*</code> translation keys from the
  22 <code>assets/minecraft/lang/*</code> files (21 languages that were purely <code>rpo.*</code> content
  removed outright; <code>es_es.json</code> cleaned of those keys while keeping the rest of the
  translations).</li>
<li><strong>Reason</strong>: OptiFine's custom texture animation (frame patching via <code>from</code>/<code>to</code>
  onto <code>enchanting_table_book.png</code>/<code>_e.png</code>) does not render correctly with EMF/ETF
  on Minecraft 26.2 — it produced visible noise/texture artifacts on the book instead of the intended
  glowing circle.</li>
<li>The pack is back to being <strong>translations-only</strong> (<code>es_ES</code>).</li>
</ul>
