<h3>Fixed</h3>
<ul>
<li><strong>Removed the broken "18 languages" layer introduced in v1.6.1.</strong> Those files did not contain real translations: the Spanish text had been copied verbatim into every locale filename (<code>en_us.json</code>, <code>de_de.json</code>, <code>fr_fr.json</code>, <code>ja_jp.json</code>, …). In practice this meant players running the game in English — or any language other than Spanish — saw Spanish item and block names for ~93 mods, because the pack's <code>en_us.json</code> overrode each mod's real English.</li>
<li>All 1,767 of those files were deleted. The pack now ships <strong><code>es_ES</code> only</strong>: every other language falls back to each mod's own bundled translation, and English is English again. Pack size drops from ~12&nbsp;MB back to ~2&nbsp;MB.</li>
</ul>

<h3>Summary</h3>
<ul>
<li>Mods with <code>es_ES</code> in the resourcepack: <strong>99</strong> · 0 pending</li>
<li>Scope reaffirmed: this pack is a curated <code>es_ES</code> translation layer, nothing else</li>
<li>No machine-translation left unchecked — new strings were reviewed key by key</li>
</ul>
