<h2>v0.0.0-beta.15 - New mods in the modpack</h2>

<p>The mod instance picked up a few new mods and several version bumps since the last release. This
version covers the ones that actually needed translation work.</p>

<h3>Added</h3>
<ul>
<li><strong>Better Party X Waystones</strong>: Spanish translation (es_ES), 48 keys.</li>
<li><strong>Sophisticated Inventory Interactions</strong>: Spanish translation (es_ES), 27 keys.</li>
</ul>

<h3>Notes</h3>
<blockquote>AppleSkin (new) already ships a complete <code>es_es.json</code> of its own, no work needed.
Configurable and TT20 (new) have no <code>lang/</code> folder at all. Armor Cosmetic, Berezka API, Carry
Mechanics, Equivalent Legacy, Tower Waystone and Warlockery all bumped versions in the instance — reviewed
and still fully covered (the Stalking Dragons ones are out of scope for this repo, the third-party ones
kept 100% key coverage after updating).</blockquote>
