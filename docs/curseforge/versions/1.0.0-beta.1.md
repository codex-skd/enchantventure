<h2>v1.0.0-beta.1 - EnchantVenture: rebrand + Magic Circle</h2>

<p>The pack is renamed <strong>EnchantVenture</strong> and is no longer translations-only: it now bundles
Spanish (<code>es_ES</code>) translations <strong>and</strong> the Enchanting Table Magic Circle by
Jacosvaldo, adapted to Minecraft 26.2.</p>

<h3>Changed</h3>
<ul>
<li><strong>Rebrand</strong>: project renamed from <code>EnchantVenture_translations</code> to
  <code>EnchantVenture</code>. New ZIP: <code>EnchantVenture-1.0.0-beta.1.zip</code>.</li>
<li>Build script renamed to <code>build_pack.py</code>; workflow doc renamed to
  <code>docs/WORKFLOW_ENCHANTVENTURE_26-2.md</code>.</li>
</ul>

<h3>Added</h3>
<ul>
<li><strong>Enchanting Table Magic Circle</strong> (by Jacosvaldo, non-commercial use, adapted to 26.2):
  <ul>
  <li>Animated, emissive magic circle around the enchanting table book (also lectern / enchanting screen).</li>
  <li><strong>11 circle colors</strong> + animation modes (<code>normal</code>, <code>bruteforce</code>,
    <code>disabled</code>) configurable in-game with <strong>Respackopts</strong> (optional).</li>
  <li><code>entity</code> shader ported to the vanilla 26.2 base (emissive alpha 252 pixels).</li>
  <li>OptiFine / EMF+ETF assets (<code>optifine/</code> CEM + animations) and Enchanting Infuser textures.</li>
  </ul>
</li>
<li><strong>22 <code>minecraft</code> language files</strong> with the circle's <code>rpo.*</code> keys
  (only the <code>minecraft</code> namespace; the rest of the pack stays <code>es_ES</code>).</li>
<li><strong>Merged</strong> <code>assets/minecraft/lang/es_es.json</code>: <code>rpo.*</code> keys +
  existing Ancient Artifacts 2 / Dungeons and Taverns keys (76 keys total).</li>
</ul>

<h3>Fixed</h3>
<ul>
<li>CI validation updated to the <code>min_format</code>/<code>max_format</code> = 88 schema.</li>
</ul>

<h3>Notes</h3>
<blockquote>Without Respackopts the default blue circle is used. The animation requires OptiFine or
EMF + ETF (installed manually by the user).</blockquote>
