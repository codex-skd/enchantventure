<h2>v0.0.0-beta.18 - Fix pack format for Minecraft 26.2</h2>

<p>Fixes the resource pack compatibility marker so the pack no longer shows as "designed for an
earlier version of Minecraft" in the resource pack selection screen.</p>

<h3>Fixed</h3>
<ul>
<li><strong>pack.mcmeta now uses <code>min_format</code>/<code>max_format</code> = 88</strong>: the previous
  <code>pack_format: 64</code> corresponded to Minecraft 1.21.7-1.21.8, so the pack was flagged as
  incompatible with 26.2. Since 1.21.9/26.x Minecraft uses <code>min_format</code>/<code>max_format</code>
  instead of the legacy <code>pack_format</code> field.</li>
</ul>

<h3>Notes</h3>
<blockquote>No translation content changed — this is a metadata-only fix. The pack is client-side and
does not require the <code>Respackopts</code> mod (it exposes no configuration options).</blockquote>
