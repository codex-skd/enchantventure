<h1 align="center">🌐 EnchantVenture Translations</h1>

<p align="center"><strong>Community Spanish (es_ES) translations for the EnchantVenture modpack — client-side resource pack, drop-in install.</strong></p>

<br>

---

<br>

<h2>✨ Overview</h2>

<p>EnchantVenture Translations is a client-side resource pack for Minecraft 26.2 that adds Spanish (<code>es_ES</code>) language files for mods included in the EnchantVenture modpack that don't ship their own — without touching the mods themselves.</p>

<br>

<h2>🎯 Coverage</h2>

<p>Translations are added incrementally, mod by mod. See the pack description or the changelog for the current list of covered mods.</p>

<br>

<h2>📥 Installation</h2>

<ol>
<li>Download <code>EnchantVenture_translations-&lt;version&gt;.zip</code>.</li>
<li>Place it in <code>resourcepacks/</code>.</li>
<li>Enable it in <strong>Options → Resource Packs</strong> (above any other resource pack that also translates the same mods, if applicable).</li>
<li>Set your game language to <strong>Español (España)</strong>.</li>
</ol>
